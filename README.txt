ABINESH A — PORTFOLIO WEBSITE
==============================

FILES
-----
index.html  Main website structure and your portfolio content
style.css   Lavender theme, layout, responsive styling and visual effects
script.js   Interactive terminal commands

HOW TO RUN
----------
1. Extract this ZIP file.
2. Open the extracted "abinesh-portfolio" folder in Visual Studio Code.
3. Open index.html in a browser.

Recommended:
- In VS Code, install the "Live Server" extension.
- Right-click index.html and choose "Open with Live Server".

CUSTOMIZATION
-------------
- Edit text and project descriptions in index.html.
- Change colours in the :root section at the top of style.css.
- Add or edit terminal commands in the commands object in script.js.

IMPORTANT
---------
This is a static front-end portfolio. No backend or database is required.
The email, GitHub and LinkedIn links are connected to the details supplied.
The pixel-art animated robot is intentionally not included yet; it can be
added as a separate final enhancement after you approve the main design.

Before publishing:
- Check all text and dates.
- Add a downloadable resume PDF if you want one.
- Test the site on mobile and desktop.
